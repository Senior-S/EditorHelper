Roads features

EditorHelper2 improves the road editing workflow with better control and faster selection.

Radius preview​

Shows road radius around selected node.

Radius includes depth​

Optional toggle to include depth in the displayed radius.

Handles and transform modes​

  • Transform handles for selected road points
  • Global/local coordinate mode
  • Snap transform value field

Selection workflow​

  • Middle-click supports multi-node selection
  • Drag rectangle selection is supported
  • Optional handle click priority toggle

Copy/paste and history keybinds​

  • Copy transform: Ctrl+B
  • Paste transform: Ctrl+N
  • Undo: Ctrl+Z
  • Redo: Ctrl+X
