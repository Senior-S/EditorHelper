# Object features

EditorHelper2 adds a full set of quality-of-life tools for object editing.

## Schematics

- Save copied object sets as schematics
- Reload and search schematics
- Apply schematic back into editor copies list
- Includes in-UI help button linking to tutorial video

## Layer mask selector

Toggle selection mask layers:

- Large
- Medium
- Small
- Structure
- Barricade

## Object preview and grid browser

- Live preview icon for selected object/item asset
- Icon grid browser for fast visual asset selection

## Precision transform editing

For single selection, exposes numeric fields for:

- Position `X/Y/Z`
- Rotation `X/Y/Z`
- Scale `X/Y/Z`

## Highlight toolkit

- Highlight all objects of selected asset type
- Highlight negative-scale objects
- Filter/highlight by mod id text
- Select all currently highlighted objects
- Cycle highlights with arrow-key keybinds

## Adjacent placement

Place selected/target object adjacent to selected world object with axis modes.

## Object tags

Assign tags to objects and auto-select other objects with same tag (with modifier-aware behavior).

## Object replacer

- Pick what you want to replace
- Pick what you want to replace it with
- Replace in radius or whole map
- Search by name
- Quick pick nearby object

## Functional copy/paste

Object copy/paste flow preserves extra object data (material index, palette GUID).
