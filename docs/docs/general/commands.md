# Module commands

## `/ammo [amount]`

Spawn default magazines for currently equipped gun.
Requires cheats.

## `/exp <amount>`

Give experience points.

## `/fly`

Toggle fly controller.
Requires cheats.

## `/heal`

Restore health, food, water, stamina and clear bleeding.

## `/i <id|guid|name> {amount}`

Spawn an item by id, guid, exact/partial name.

## `/jump`

Teleport to surface under your aim ray.

## `/maxskills`

Unlock all skills.

## `/resetskills`

Reset all skills to level 0.

## `/tp <location|player|waypoint|bed>`

Alias implementation of vanilla teleport command behavior.

## `/v <id|guid|name>`

Spawn vehicle by id, guid, exact/partial name.
