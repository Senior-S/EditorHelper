# Feature overview

This page gives a simple overview of what EditorHelper2 adds.

## Main menu

- **Extensions Menu**: turn optional EditorHelper2 features on or off.
- **News panel**: see module updates, announcements, and community links.

## Editor dashboard and pause menu

- **Join Singleplayer / Join Editor**: quick testing loop between editor and singleplayer.
- **Prompts**: clear confirmation and alert popups for actions.
- **Documentation button**: open this documentation site from inside the editor.
- **Keybind menu**: rebind EditorHelper2 shortcuts.
- **Excel export**: export map asset data into a spreadsheet.
- **Map resolution tools**: generate higher-resolution map/satellite outputs.
- **Map optimizer**: export an optimized mod folder from the installed mod assets used by the current map.

## Environment tools

- **Road tools**: better handles, snapping, and multi-selection workflow.
- **Navigation tools**: transform and scale navigation areas more precisely.
- **Node names**: show node names directly in the world.

## Level tools

- **Object precision tools**: exact position/rotation/scale editing.
- **Object highlight tools**: highlight by asset type, bad scale, or mod id.
- **Object icon tools**: preview icons and grid-based object browsing.
- **Schematics**: save and load reusable object setups.
- **Extra object tools**: adjacent placement, layer mask controls, and object tags.
- **Object replacer**: replace one object type with another in a radius or whole map.
- **Visibility region tools**: visualize regions and read clearer region info.

## Terrain tools

- **Heightmap importer**: import PNG/JPG, square 16-bit raw, or `.heightmap` terrain data into the whole map or current tile.
- **Foliage density and collection tools**: edit foliage values and collection contents live.
- **Foliage icons**: preview and grid browsing for foliage assets.
- **Resource replacer**: replace resource assets in selected area or whole map.
- **Material paint height limits**: limit splatmap painting to selected height range.
- **Tile duplicate cleaner**: remove duplicate tile material layers.

## Spawns tab status

At the moment, EditorHelper2 does not add dedicated extra tools specifically for the Animals or Vehicles spawn tabs.
