# General features

These features are available across the module.

## Keybind system

- You can rebind EditorHelper2 controls from **Editor Pause -> EditorHelper2 Keybinds**.
- Common shortcuts (undo/redo, copy/paste transform, highlight navigation, and more) are included by default.

## Singleplayer roundtrip

- **Join Singleplayer** lets you test your map quickly from editor mode.
- **Join Editor** appears in singleplayer so you can jump back to editing without restarting your workflow.

## Documentation and update flow

- The pause menu has a **Documentation** button that opens this Docusaurus site.
- The main menu news panel shows module news and update notices.
