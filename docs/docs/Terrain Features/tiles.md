# Tiles features

This tool helps clean up terrain tile material data.

## Remove duplicate material layers

Adds a **Remove Duplicates** action that:

- finds duplicate splatmap material layers on selected tile
- remaps and normalizes splatmap weights
- refreshes the tile setup so changes save correctly
