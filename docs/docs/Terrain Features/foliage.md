# Foliage features

EditorHelper2 adds several tools for faster foliage and resource workflows.

## Live foliage editor

- Live density editing for selected foliage asset
- Explicit save button writes density to file

## Foliage icons

- Preview icon for selected foliage asset
- Icon grid for foliage asset browsing and quick selection

## Live collection editor

- Create new collection asset files
- Toggle collection membership for foliage entries
- Edit per-entry weight
- Save collection asset to file

## Resource replacer

- Source/target selection modes
- Radius-based or whole-map replacement
- Search/filter tooling
- Optional transform behavior for new assets
- Cleanup tool for broken resource entries
