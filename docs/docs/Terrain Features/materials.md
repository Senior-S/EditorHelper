# Materials features

This section adds better control when painting terrain materials.

## Height-limited splatmap paint

- Toggle to enforce min/max height limits while painting splatmap
- Min/Max height numeric fields
- Brush world position display
- Brush position text color indicates if current brush position is within limits

## Brush height keybind helpers

- Set min height from current brush position
- Set max height from current brush position

You can change these shortcuts in the EditorHelper2 keybind menu.
