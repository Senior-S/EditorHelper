# EditorHelper2 documentation

Welcome to the official EditorHelper2 docs.

## What is EditorHelper2?

EditorHelper2 is a map-making helper module for Unturned.
It adds tools that make building, editing, and polishing maps faster and easier.

## What you will find here

- A clear list of available features
- Where each feature appears in the editor
- Quick explanations for how each tool is useful
