# Modularn

Modularn is a launcher for Unturned that helps you manage game modules and mods more easily.

Use it when you want a simpler workflow for installing, organizing, and switching module or mod setups without manually moving files around every time.

## Downloads

- **Portable version**: [Download Modularn Portable](https://ps.sshost.club/s/ModularnPortable)
- **Installer version**: [Download Modularn Installer](https://ps.sshost.club/s/Modularn)

The portable version can be kept as a standalone folder. The installer version sets up Modularn through a normal Windows installer flow.
